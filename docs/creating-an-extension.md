# Creating an extension

Extensions are generated by tabmill from a recipe (ADR-0008). Never edit
`$TABMILL_WORKSPACE/extensions/` — change the recipe or a template and regenerate.

## 1. Idea → recipe

In the tabmill repo (the `tabmill-new-extension` skill walks through it):

```
uv run tabmill status                                # what exists; avoid duplicates
uv run tabmill new <slug> [--template popup|side-panel|maps-overlay]   # writes the recipe
```

Fill every `‹FILL›` in `recipes/<slug>/extension.yaml`: one-sentence single purpose, name
(≤ 75), summary (≤ 132), funnel fields. Keep `activeTab`; add a permission only with a
justification. No real CTA yet → `https://<name>.example/...` (warns in dev, blocks release).

## 2. Feature code

`recipes/<slug>/src/feature/index.ts` exports `mount(root: HTMLElement)` — it replaces the
template stub. Page access: a runtime content script in `src/entrypoints/<name>.content.ts`
(`registration: "runtime"`) called with `runInTab("/content-scripts/<name>.js", guard)` from
`@/lib/inject`. Unit tests in `tests/unit/`, smoke tests in `tests/smoke/`. Any runtime npm
dependency → a DECISIONS.md row first, then `dependencies:` in the YAML.

Shared code every extension gets (`templates/extension/_shared/`): branded shell + "Built by
Lamill" footer + UTM CTA (`@/lib/brand`), `@/lib/inject`, typed messaging, Lamill tokens
(`@/lib/shell.css`), Playwright fixtures.

## 3. Generate, build, test

```
uv run tabmill new <slug>        # again, recipe filled: register + generate into the workspace
uv run tabmill try <slug> [--url URL] [--dev]  # build + Chromium in docker, window on your desktop
uv run tabmill check <slug>      # typecheck + unit + smoke + store-policy lint (docker)
uv run tabmill status            # where each extension stands + the next command
```

All Node work runs in the builder container; nothing Node runs on the host.

## 4. Before release

`uv run tabmill ship <slug>` renders the store images, drafts the listing, writes the tool-page
brief, runs release lint and collects the upload folder. Follow the `tabmill-release` skill.
Single steps (`build`, `dev`, `lint`, `zip`, `assets`, …) are under `uv run tabmill advanced`. First publish of a new item is manual in
the Developer Dashboard (the API can't create items). Full workflow: [publishing.md](publishing.md).
